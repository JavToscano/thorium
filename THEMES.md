# Making a Thorium theme

A theme changes how Thorium looks and sounds: colors, shapes, motion, an animated background, falling particles, tab icons and labels, sound effects and the font. A theme is **a folder with a `theme.json` and the files it names**; no code and no rebuild.

## Installing a theme

Copy the folder to `Thorium/themes/` on your device's storage (`/storage/emulated/0/Thorium/themes/<your-theme>/`), then open **Settings → Theme** and press **A** on it. It applies at once. A theme installed there with the same `id` as a bundled one replaces it.

The app ships with **Thorium** (the default look) and two examples that use every feature: **Sakura Night** (anime) and **Hyrule Dawn** (fantasy adventure). They live in `app/src/main/assets/themes/`, and the scripts that drew their art and synthesised their sounds are in `tools/themes/`.

**Fan themes and other people's work:** art, music, logos and fonts from games, anime and other franchises belong to their owners. Thorium does not include any. A theme made from them is fine for your own device (copy the folder to `Thorium/themes/`), but do not redistribute it; make original art, or use assets whose license allows it.

## The smallest theme

```json
{ "id": "mint", "name": "Mint", "colors": { "accent": "#5CFFB1" } }
```

Everything a theme leaves out (or gets wrong) falls back to the default look, so a typo never breaks the app. Only `id` is required (letters, digits, `-` and `_`).

## `theme.json` reference

Colors are `#RRGGBB` or `#RRGGBBAA` (web order, alpha last). Sizes are in dp. Paths are relative to the theme folder and cannot leave it.

| Field | Meaning |
|---|---|
| `id`, `name`, `author`, `description`, `version` | Shown in Settings → Theme |
| `colors.backgroundTop`, `backgroundBottom` | Vertical gradient behind everything |
| `colors.accent`, `accentAlt` | Highlight color and its partner (focus border, indicator, glow) |
| `colors.panel`, `panelFocused` | Rows and buttons, normal and focused (alpha lets the background show through) |
| `colors.textPrimary`, `textSecondary` | Main and secondary text |
| `colors.success`, `danger`, `warning` | Download states, favorite star |
| `colors.onAccent` | Text on an accent-colored button |
| `shapes.cardRadius`, `panelRadius`, `border` | Corner radii and focus border width (0 to 40 / 0 to 8) |
| `motion.focusScale` | How much a focused card grows (1.0 to 1.4) |
| `motion.focusLift` | How far it rises, in dp (0 to 24) |
| `motion.glow`, `glowPulse`, `shine` | Halo behind the focused item, its slow breathing, and the sweep of light |
| `motion.entrance` | Cards slide in one after another when a screen opens |
| `motion.tabSlideMs`, `pageMs` | Duration of the tab indicator and page slides |
| `background.layers` | List of `{ "image", "parallax", "drift" }`, back to front. `parallax` (0 to 1) is how much a layer shifts when you change tab; `drift` (-1 to 1) a slow sway |
| `background.vignette` | Darkening at the edges (0 to 1) |
| `background.gradientShift` | Slowly moving ambient light over the gradient |
| `particles` | `kind` (`petal`, `snow` or `orb`), `count` (up to 60), `speed`, `sizeMin`, `sizeMax`, `colors` (list), `sway` |
| `tabs` | For `home`, `systems`, `favorites`, `downloads`, `settings`: `{ "icon": "icons/x.png", "sub": "second label" }` |
| `sounds` | Event name to file (see below) |
| `font` | `{ "regular": "fonts/a.ttf", "bold": "fonts/b.ttf" }` |

### Sound events

`move`, `select`, `back`, `tab`, `favorite`, `menu`, `launch`, `startup`, `done` (a download finished) and `error` (a download failed). Use short WAV or OGG files (a fraction of a second, except `startup`); they are played with `SoundPool`, so keep them small. `move` only plays when the focus actually changes.

### Images

- **Background layers:** PNG, WebP or JPG, around 1920×1080. They are drawn 14% larger than the screen so parallax never shows an edge: keep important things away from the borders. Use transparency on the upper layers.
- **Tab icons:** PNG, about 128×128, **white on transparent**: Thorium tints them with the accent or secondary color.
- Keep the whole theme to a few MB; it is decoded when the theme is applied.

### Fonts

TTF or OTF. A full CJK font is several MB, so cut it down to the characters you need (`tools/themes/subset_font.py` shows how, with `fontTools`). Check the font's license allows it and ship the license text next to it.

## Tips

- Test with **Settings → Theme → Animations Off** too: a calmer screen must still look good.
- Panels with some transparency (`panel` alpha around `CC`) let the background through and look like glass; keep enough contrast for the text.
- Players can turn the sounds off separately (Settings → Theme → Theme sounds).
